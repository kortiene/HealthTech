Architecture & composants

Flux de données : local-first / zero-knowledge — le serveur ne voit jamais de plaintext, de clé ou de PII.

📱 app-patient (Flutter/Android)

  • Création de compte + clé maîtresse (Android Keystore)
  • Chiffrement local AES-256-GCM + gzip
  • Génération QR éphémère (~120 s)
  • Sauvegarde cloud (blob opaque)
  • Queue offline SQLCipher (#21)
⇄

🔐 backend (Rust/Axum)

  • Proxy dumb : PUT/GET /blob/{uuid}
  • Aucune clé, aucun déchiffrement
  • Capability URLs HMAC-SHA256 (médias)
  • Hébergement souverain Côte d'Ivoire
  • MinIO + PostgreSQL
⇄

🩺 app-medecin (Preact/TypeScript PWA)

  • Scan QR patient
  • Déchiffrement RAM-only (WASM crypto-core)
  • Ajout notes/ordonnances
  • Wipe mémoire en fin de session
  • Interface zero-menu, 4 étapes / 3 écrans
crypto-core (Rust) — bibliothèque partagée : AES-256-GCM, PBKDF2 (600 k / 210 k itérations), nonce aléatoire 96 bits, tag GCM 128 bits. Utilisée par Flutter (via flutter_rust_bridge), PWA (WASM) et backend (tests). Jamais de doublon d'implémentation.
