Blockers M4 — Chemin critique vers le lancement

#8
Hébergement souverain (Côte d'Ivoire)

Sélection de l'opérateur + provisionnement MinIO / PostgreSQL in-country. Sans cela, le backend tourne en MemoryStore (données perdues au redémarrage) et la conformité ARTCI de résidence des données ne peut pas être attestée.

#30
Homologation ARTCI — 0/22 exigences juridiquement validées

8 écarts documentés (ECART-01…08 : rétention, suppression, DPO, mineurs, break-glass…). La soumission du dossier et l'autorisation commerciale sont bloquées jusqu'à résolution + sign-off du conseil juridique.

#25
Pentest externe

Scope défini, vendor à choisir. Toute vulnérabilité Critical/High bloque le lancement. Timing : post-M3 complete.

#17 / #108
Crypto WASM pour la PWA médecin

AES-256-GCM dans le Web Worker (RAM-only), scan QR caméra réel. Skippé pour ne pas casser les tests E2E locaux (incompatible avec le stub XOR dev Flutter). Obligatoire avant pilote terrain.
